このWebサイトでは、ITの基本、プログラミング、 ネットワーク、サイバーセキュリティについて紹介します。

ITとは

ITは「Information Technology」の略です。 コンピュータやインターネットを使って、 情報を管理・活用する技術です。

Programming

HTML

Webページの基本構造を作る言語です。

CSS

Webページの色やデザインを作ります。

JavaScript

Webページに動きや機能を追加します。

Java

多くのシステム開発で使われるプログラミング言語です。

Network

ネットワークは、コンピュータやスマートフォンなどを 接続して情報を送受信する仕組みです。

Cyber Security

サイバーセキュリティは、コンピュータやネットワーク、 大切な情報をサイバー攻撃から守るための技術です。
